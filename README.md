# Bergfelds – statisk webbplats

Webbplatsen använder endast HTML, CSS och JavaScript. Den har inga paket, ramverk eller byggsteg.

Öppna `index.html` direkt i en webbläsare för att köra den lokalt. Webbplatsen består av sju HTML-sidor:

- `index.html` – startsida
- `butiken.html` – butik och besök
- `sortiment.html` – produktområden och leverantörer
- `du-som-kund.html` – kundlöfte och service
- `om-bergfelds.html` – företagets historia och värderingar
- `kontakta-oss.html` – kontaktuppgifter
- `integritetspolicy.html` – integritetspolicy

Sidorna delar stilmallen `style.css` och funktionalitet i `main.js`.

## GitHub Pages

Öppna **Settings → Pages**, välj **Deploy from a branch**, sedan `main` och `/ (root)`. Alla lokala resurser använder relativa sökvägar och fungerar därför även på en GitHub Pages-projektsida.
